📚 수업교체 찾기 — 사용 안내서

교사를 위한 수업교체 탐색 방법 안내

⚙ 설정 안내

① 내 이름 선택
상단 드롭다운에서 본인의 이름을 선택합니다. 이후 탐색 시 내 수업 정보가 자동으로 표시됩니다.

② 교체 제외 교시 설정
교체 후보에서 제외할 교시를 미리 등록해 두면 탐색 결과에서 해당 교시는 표시되지 않습니다.

예시
· 월요일 1교시 — 자율활동으로 제외
· 수요일 5교시, 수요일 6교시 — 창의적 체험 활동으로 제외
· 수요일 1교시, 목요일 1교시 — 개인이 원하지 않는 시간을 제외할 수도 있습니다.

③ 특정 날짜 제외
매주 반복이 아닌 특정 날짜의 특정 교시만 제외하려면 오른쪽 특정 날짜 항목에 날짜와 교시를 입력 후 추가합니다.

1 탐색 안내 — 결강 정보 입력
  • 결강 날짜를 선택합니다.
  • 결강 교시를 선택합니다. 해당 교시에 내 수업이 있으면 내 수업 정보가 자동으로 표시됩니다.
  • 교체 가능 교사 탐색 버튼을 클릭합니다.
내 수업 정보가 표시되지 않으면 해당 교시에 수업이 없는 것입니다. 날짜와 교시를 다시 확인해 주세요.
2 탐색 안내 — 교체 교사 선택

같은 학급 수업을 담당하는 교사 목록이 나타납니다. 각 항목의 의미는 아래와 같습니다.

  • ✓ 가능  결강 교시에 수업이 없어 바로 교체 가능한 교사
  • ⚠️ 충돌  결강 교시에 다른 수업이 있는 교사 — 연쇄 교체 가능
  • 06월17일(수) 와 같이 취소선이 있는 날짜 — 교체 제외 설정된 날짜로 선택 불가
  • ⚠️ 표시 날짜 — 해당 날짜에 다른 수업과 충돌이 있는 날짜
  • 원하는 교사의 대체수업 교시 버튼을 클릭합니다.
  • 아래 펼쳐지는 날짜 목록에서 대체수업 날짜를 클릭합니다.
  • 선택이 완료되면 장바구니 담기 버튼이 활성화됩니다.
3 탐색 안내 — 장바구니 담기

교사와 날짜를 선택한 후 장바구니 담기 버튼을 누르면 해당 교체 항목이 저장됩니다.

여러 교시를 한 번에 교체하려면
담기 후 나타나는 "추가로 교체할 수업이 있나요?" 팝업에서 탐색 계속을 클릭하면 결과 화면을 유지한 채 추가 교시를 이어서 탐색할 수 있습니다.
4 탐색 안내 — 연쇄 교체

결강 교시에 다른 수업이 있는 교사(⚠️ 충돌)도 연쇄 교체를 통해 교체할 수 있습니다.

  • 충돌 교사 항목에서 대체수업 교시를 선택합니다.
    결강일에 해당 교시 대신 가르칠 수업 교시입니다.
  • 대체수업 날짜를 선택하면 아래에 연쇄 교체 교사 목록이 펼쳐집니다.
  • 연쇄 교체 목록에서 ✓ 가능 표시 교사를 찾아 날짜를 선택합니다.
  • 모든 선택이 완료되면 장바구니 담기를 클릭합니다.
연쇄 교체 목록에도 충돌 교사만 있다면 다른 교사 또는 다른 교시를 선택해 보세요.
🛒 장바구니 안내

장바구니 탭에서 교체 항목 전체를 확인할 수 있습니다. 각 항목은 담당수업(결강)과 대체수업이 표로 정리되어 있습니다.

대체수업계획서로 바로 활용하기
장바구니의 표 영역을 드래그하여 복사(Ctrl+C)한 뒤, 대체수업계획서 양식에 붙여넣기(Ctrl+V)하면 표 형식이 그대로 입력됩니다. 별도 입력 없이 바로 제출할 수 있습니다.

불필요한 항목은 각 항목 우측의 ✕ 삭제 버튼으로 제거하거나, 상단 전체 삭제 버튼으로 모두 지울 수 있습니다.
